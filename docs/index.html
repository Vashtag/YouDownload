One-time setup

This page runs in your browser, but YouTube doesn't let websites download videos directly. A small helper program on your computer does the downloading. Start it once and keep it running while you use this page.

  1. Install Python 3 and ffmpeg (macOS: brew install ffmpeg, Windows: winget install ffmpeg).
  2. Download the helper: YouDownload.zip, then unzip it.
  3. In a terminal, inside that folder, run: 
    pip install -r requirements.txt
python app.py
  4. Come back here. This page connects on its own.

If your browser asks to let this site access devices on your local network, choose Allow. Chrome, Edge and Firefox work best. Safari blocks pages from reaching the helper.

Only change this if you run the helper on a different port or another machine.

Only download content you own or have permission to download.
