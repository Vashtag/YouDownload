Download server

Browsers aren't allowed to download from YouTube directly, so this page uses a cobalt server to do it. Enter the address of a cobalt instance you run, or one whose owner gave you access. This is saved in your browser only.

How do I run my own cobalt server?

Follow cobalt's instance guide. With Docker it's roughly: 

docker run -d -p 9000:9000 \
  -e API_URL=https://your-domain/ \
  -e CORS_WILDCARD=1 \
  ghcr.io/imputnet/cobalt:11

Note: the public api.cobalt.tools server uses bot protection and isn't meant to be used by other sites.
